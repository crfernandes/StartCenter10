# StartCenter10

Centraliza o botão Iniciar do Windows 10 utilizando APIs Win32.

## Status

- [x] Localização do botão Start
- [x] Reposicionamento via MoveWindow
- [x] Centralização automática
- [x] Persistência após reinicialização
- [x] Centralização do menu Iniciar
- [ ] Validação multimonitores
- [ ] Testes finais 

## Projeto

Projeto criado durante estudos de engenharia reversa da taskbar do Windows 10.
